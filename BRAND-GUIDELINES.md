# Mathora Brand & Design System — Version 6.1

## Brand idea

**Mathora makes mathematical performance visible.**

Mathora should feel:
- precise
- evidence-led
- calm
- modern
- premium
- academically credible

It should not feel:
- childish
- overly decorative
- like a generic tutoring marketplace
- dependent on neon gradients or “AI” visual clichés

## Product family

- **Mathora Assess** — diagnostics, assessments and reports
- **Mathora Learn** — tutoring and academic support
- **Mathora Review** — homework and exam-paper review
- **Mathora Schools** — intervention, CPD and consultancy
- **Mathora Studio** — future teacher tools and resource creation

## Logo

The mark combines:
1. a geometric M
2. a coordinate-axis baseline
3. a plotted point

The logo works in one colour and remains recognisable at small sizes.

Use:
- `assets/brand/mathora-logo.svg` on dark backgrounds
- `assets/brand/mathora-mark-dark.svg` on white backgrounds
- `assets/brand/mathora-wordmark.svg` in documents and proposals
- `assets/brand/favicon.svg` for browser tabs

Do not:
- stretch the logo
- rotate it
- add drop shadows
- recolour individual parts outside the official palette
- place it on visually busy photography

## Colour system

| Name | Hex | Main use |
|---|---|---|
| Midnight | `#07111F` | Navigation, premium surfaces, headings |
| Mathora Blue | `#296DFF` | Primary actions, progress, links |
| Focus Blue | `#6FA7FF` | Supporting accent on dark backgrounds |
| Canvas | `#F6F8FB` | Main page background |
| White | `#FFFFFF` | Cards and documents |
| Progress | `#0F9F6E` | Successful completion |
| Warning | `#D98A00` | Caution and deadlines |
| Error | `#D84B63` | Validation and failures |

## Typography

- **Manrope** — headlines and product names
- **DM Sans** — body copy, forms and navigation
- **JetBrains Mono** — timers, scores, percentages and identifiers
- **KaTeX** — mathematical expressions

## Voice

Prefer:
- “Identify the gap.”
- “Show the method.”
- “Build the next step.”
- “Evidence before intervention.”
- “Understand where marks are being lost.”

Avoid:
- inflated promises
- fake statistics
- exaggerated grade guarantees
- excessive exclamation marks
- jargon without explanation

## Components

Use only:
- 4 button styles
- 3 card surface styles
- 3 badge states
- one form system
- one table system
- one report visual language

## Mobile rules

- Minimum touch target: 44 px
- Avoid four-column layouts below 950 px
- Use single-column forms below 680 px
- Keep key actions visible without horizontal scrolling
- Whiteboards should open full-screen on narrow devices
