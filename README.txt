MATHORA STAGE 2

This version includes:
- Full homepage
- Student registration form
- Dynamic qualification, exam board and level options
- Form validation
- Temporary browser storage using localStorage
- Assessment welcome page

HOW TO USE
1. Replace the old files in your GitHub repository with these files.
2. Upload the two new JavaScript files: register.js and test.js.
3. Upload the new test.html file.
4. Commit the changes.
5. Open the website and click Start assessment.

IMPORTANT
The student information is currently saved only in the student's own browser.
It is not yet sent to you. Supabase storage will be added after the test interface is built.
