GITHUB STEPS
1. Extract this ZIP.
2. Open your GitHub Mathora repository.
3. Click Add file → Upload files.
4. Upload every file inside the extracted folder.
5. Allow GitHub to replace existing files.
6. Commit with: Connect Mathora to Supabase
7. Wait around one minute.
8. Hard refresh the published site:
   Mac: Command + Shift + R
   Windows: Ctrl + Shift + R

TEST

7. Check Supabase:

   Table Editor → answers
