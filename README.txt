MATHORA V2 — TIMED MULTIPLE-CHOICE DIAGNOSTICS

WHAT IS NEW
- Every question is multiple choice.
- Every question requires working.
- Student must either save a whiteboard or upload a handwritten solution.
- Different 12-question tests load for each exam board and level.
- Total countdown timer.
- Time spent per question.
- Automatic submission attempt when time reaches zero.
- Supabase stores:
  selected option
  correct option
  whether correct
  time per question
  total test time
  working method
  uploaded images and whiteboards
