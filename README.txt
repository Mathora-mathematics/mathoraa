MATHORA STARTER WEBSITE

FILES
- index.html: homepage
- register.html: temporary registration page
- style.css: all design and mobile styling
- script.js: mobile menu and automatic footer year

HOW TO TEST
1. Open the folder.
2. Double-click index.html.
3. The website will open in your browser.

HOW TO PUBLISH
1. Create a GitHub repository.
2. Upload all four files.
3. Open Settings > Pages.
4. Choose Deploy from a branch.
5. Select main and /(root).
6. Save.
